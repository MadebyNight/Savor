# 食光 · 开发规划

v0.4 · 2026-09-18

## 目标、架构、技术栈

完成产品需求确认中的 MVP；沿用 React + Vite 高保真界面，以 Capacitor 交付 Android APK。原生 SQLite 表保存带版本的结构化 JSON 状态，私有文件目录保存图片；SharedPreferences 保存普通偏好；Keystore AES-GCM 保存凭据。此 JSON 聚合存储方案降低个人应用迁移与整包同步复杂度，仍使用 SQLite 事务保证状态写入原子性。

V1.2.1 增加菜单预计营养与周回顾，仍排除个人实际摄入和健康目标；新增功能按三份 V1.2.1 文档分批实施。公开链接使用 Readability 提取正文，Android 支持有上限的 HTTPS 短链接跳转及手机浏览器请求标识；不接入登录态或复杂爬虫，无法公开读取时保留文字、截图入口。安全限于必要凭据保护、输入校验与不静默覆盖，不建设账号、审计或专项渗透体系。
