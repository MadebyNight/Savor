# V1.2.2 界面整合

2026-09-23，用户已确认方案并授权实施。版本：npm / Android 1.2.2，versionCode 5。

## 范围与视觉规范

合并最近几轮紧凑布局、采购勾选、冰箱推荐、统一导入入口，本轮增加菜谱筛选及次级页面统一布局。不改变采购计算、菜单快照、营养口径和业务存储结构。

- 暖白正文、浅灰绿工具区、深橄榄标题、暖黄主按钮。Logo 独立浅底，标题适度加粗，右侧操作降低视觉权重。
- 一级页面保持约 52px 顶栏、56px 底栏；搜索内置筛选，不增加常驻筛选行。
- 分类包含内置与用户已有分类。时长为不限、15 分钟内、16～30 分钟、30 分钟以上、未填写；时长大于 15 且不超过 30 归入中间区间，空值与旧数据 0 归入未填写。
- 分类、时长、关键词同时生效；打开筛选使用草稿，确定才应用，关闭不更改；与点单和冰箱独立。
- 长内容使用统一次级页面容器，标题与必要主操作固定、正文滚动；编辑、导入、设置隐藏一级底栏，返回保留任务和草稿。
- 菜谱详情缩略图可放大，更多操作收起编辑和删除；批量菜谱草稿折叠逐项编辑；食材保持两列对齐。
- 历史菜单按周、七天切换阅读，复制整周独立折叠；餐次仍从已确认菜品选择，不改变采购规则。
- 营养回顾保留建议和目标周每日切换；高级计算独立页面，计算详情与参考资料折叠。
- 通用短选择与危险确认保留应用样式，保留删除、覆盖及数据缺失的必要说明。

## 实施与验证

1. 公共样式与 Dialog 页面容器。
2. 菜谱分类、时长筛选与边界测试。
3. 菜谱、识别、食材、餐次、历史、设置和营养页面调整。
4. 构建、浏览器小屏/大字号与 Android 同签名覆盖验收。

变更可按 Git 文件差异回退；没有数据迁移，不清除应用数据。测试结果在开发进度中补充，未通过验收前不宣称全部完成。第三方评估中未获确认的功能扩展不随本版实施。

已完成本轮范围，23 项相关单测、11 组浏览器回归与 OPPO 真机验收通过，原签名覆盖安装至 1.2.2 / 5，业务哈希一致。日志、截图和范围边界见《开发进度》本版记录。未进行真实 AI 或云端同步请求。
