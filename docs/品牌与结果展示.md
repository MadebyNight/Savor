# 食光品牌与结果展示

## 识别结果交互

AI 菜谱和小票识别完成后自动打开独立核对窗口，背景遮罩隔离设置页。结果明确标为“尚未入库”；用户可以编辑、选择条目，再确认保存。关闭、稍后处理和系统返回只关闭窗口，保留草稿；设置页用“查看待保存草稿”重新打开，不再铺开结果编辑器。

部分保存后保留未选条目；全部保存后关闭窗口。保存期间禁止再次保存和关闭窗口。空结果与识别失败使用独立结果提示，失败保留原文和已有草稿，停止等待后忽略迟到结果。

展示规则：涉及核对、覆盖或入库的结果使用独立窗口；输入字段、普通说明和实时筛选仍在原位，避免为每次轻操作增加弹窗。

## Logo 参考与设计

调研日期：2026-09-20。参考官方商店发布的图标与产品站点：

| 案例 | 观察 | 食光采用的原则 |
| --- | --- | --- |
| [Kitchen Stories](https://apps.apple.com/us/app/kitchen-stories-easy-recipes/id771068291) | 黄色底与简洁的白色蒸汽符号 | 简化轮廓，保留小尺寸辨识度 |
| [Samsung Food](https://apps.apple.com/us/app/samsung-food-meal-planner/id1133637674) | 暖色底与碗形烹饪符号 | 用餐饮意象表达用途，避免文字堆叠 |
| [Paprika](https://www.paprikaapp.com/) | 菜谱、菜单和采购管理的完整产品定位 | 品牌标识跨功能复用，页面标题独立表达功能 |

上述内容是设计观察，不表示效果经过用户研究验证。未复制任何第三方图形。

食光新标志为原创矢量家常饭碗：可辨认的碗、暖黄番茄与绿叶直接表达食物，采用轻盈的小清新风格。配色直接复用当前程序：背景浅灰绿 `#EEF1E5`、食材暖黄 `#F8CB4A`、米白碗 `#FCFCF9`、叶片及轮廓灰绿 `#758266`，辅助色 `#FFF2BF` 和 `#A3A991` 同样取自现有样式。没有更改应用整体主题。
