## 2. 总体判断

当前 APP 配色舒服、基本秩序清楚，但“把功能摆整齐”的感觉强于“围绕内容精心设计”的感觉。最值得改的是视觉重心和页面节奏。

米白、暖黄、灰绿适合“食光”，温和、有生活感，值得保留。但搜索框、分类、按钮、内容区域都比较强调自己的边界；食物图片偏小，辅助文字大量使用灰绿，页面容易显得平均、偏淡。

建议方向：

1. 让菜名、食材名、当天安排成为第一视觉层。标题与辅助信息通过字重、间距和颜色共同区分。
2. 减少普通控件的装饰重量。搜索框不必同时承担明显描边、阴影和大圆角，让工具退后。
3. 收紧黄色的使用范围：主提交用实黄，选中状态用浅黄，普通操作以中性样式为主。
4. 保留已有紧凑布局，不继续全面压缩行高；在相同空间内重新分配注意力，并保留触摸面积和字体缩放适配。
5. 让食物和生活内容更突出，让工具控件更安静。

## 3. 点单页：加号比菜品更抢眼

### 观察

右侧连续出现黄色圆形加号，底部还有深绿与亮黄确认栏，形成很强的操作视觉；食物图片只是较小的缩略图。连续重复的无图餐具占位图也削弱了菜品区别。

### 建议

- 未选中时，加号改成轻描边或浅底；选中后再增强颜色和数量反馈，保留现有触摸面积。
- 菜名更突出，食材摘要更安静；图片统一裁切比例和视觉质量。
- 重新设计无图菜品占位图，可采用统一风格的分类占位图。
- “已选 0 份”时降低确认栏存在感，有选择后再突出。
- 左侧分类数量进一步弱化，避免与菜名争夺注意力。

预期效果：第一眼看到想吃的菜，第二眼才是怎么添加。保留当前点单效率，不必改成大图瀑布流。

## 4. 周菜单：优先重设计主次关系

### 观察

日期区、标语、五餐表格、营养回顾入口、当日营养依次展开。营养回顾入口是比较醒目的大卡片，并排在当日营养之前。

### 建议

阅读顺序调整为：**选中日期 → 当天五餐 → 当日预计营养 → 本周回顾**。

- 日期区保持清楚，减少它与标语占用的纵向空间。
- 保留“一饭一饮 三餐四季”，以轻量题签呈现。
- 五餐保留紧凑结构，让餐次标签退后、菜名成为主角，减少表格的机械感。
- 空餐次不必重复五个带底色的“添加菜品”块，改为轻提示与小加号，整行仍可点击。
- 回顾入口收成紧凑导航行，放在当日营养之后；有待查看内容时再增加状态强调。

这是预计对整体品质提升最明显的一处。后续需同时检查空菜单与已安排完整五餐的状态。

## 5. 冰箱：保留风险层级，弱化工具重量

### 观察

过期红、临期黄、正常白的区分有效，值得保留。上方搜索、分类、三个添加按钮连续堆叠，视觉上仍像一组管理工具；库存行内的名称、分类、数量、期限比较平行。

### 建议

- 保留拍摄、相册、手动三个直接入口，让它们更像轻工具栏，减少三个独立白色按钮块的重量。
- 名称和期限作为主要信息，数量其次，分类进一步弱化，必要时并入辅助行。
- 过期和临期继续明确强调，但减少背景、侧边、标签同时争抢注意力的情况。
- 将“保存期待补充”设计成紧凑且可理解的待完善状态，避免长状态文案持续挤占名称空间。

预期效果：先看见有哪些食材、哪些需要优先处理。美化不得削弱期限状态的可理解性。

## 6. 菜篮子：保留清单感，建立完成反馈

### 观察

每行重复“待买 · 分类”，都用偏红文字，数量又用金棕色。普通采购事项带着提醒意味，整页重点比较分散。

### 建议

- 顶部用紧凑的“已买 / 总计”建立完成感，可配细进度条。
- 未勾选已表达待买，逐行“待买”可省去，分类回归中性辅助文字。
- 食材名和数量清晰对齐，单位比数字轻。
- 已买条目降低视觉权重，让未完成事项自然突出。
- 评估把左侧分类改为顶部紧凑筛选，将宽度还给清单。

美感应来自整齐、清晰和完成反馈，不适合加入食物大图或大量独立卡片。

## 7. 营养回顾：先展示已有内容

### 观察

“下周怎么安排”的说明和生成按钮占据较大首屏面积，实际每日营养在下面，页面更像 AI 功能介绍页。接近全屏的弹窗保留了遮罩和边缘，压缩内容空间；空数据状态的大卡片显得内容不足。

### 建议

- 顶部：目标周与简短概况。
- 中部：已有营养数据、估算完整程度、每日切换。
- 后部：下周建议与生成操作。
- 评估改为独立全屏页，以适应持续阅读和日期切换。
- 无数据时采用紧凑空状态，避免大卡片里仅放“—”。未知值不能改为零。

预计营养与实际摄入的区分继续保留；布局调整不能将估算包装为个人健康结论。

## 8. 导入、设置与菜谱库：形成各自的页面性格

| 页面 | 观察 | 建议方向 |
| --- | --- | --- |
| 导入菜谱 | 空文本框占据较大面积，图片入口与正文输入缺少整体组织 | 做成完整素材输入区，让图片入口、缩略图、正文彼此关联；输入框随内容适度增长，保存草稿降低权重 |
| 设置 | 长标题横向分页，再叠加标题、复选框、大输入框，表单感较强 | 改为分组设置列表，进入具体配置页；开关类事项用开关，星期与时间采用紧凑设置行 |
| 菜谱库 | 当前实现是小缩略图加分隔线列表，收藏感偏弱 | 与点单区分：点单重效率，菜谱库可适度提高图片占比，让封面、菜名、分类形成更有辨识度的收藏条目 |

菜谱库建议需补充最新实屏观察后再决定布局比例。
