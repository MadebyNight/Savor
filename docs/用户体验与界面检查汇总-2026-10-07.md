# 食光用户体验与界面检查汇总

检查基线：V2.1.11，`d3e0ef3`。整理日期：2026-10-07。本文合并 2026-09-22 的[功能评估](用户体验与功能评估-2026-09-22.md)、2026-09-23 的[整合评估](用户体验与美学优化整合评估-2026-09-23.md)、[美学检查](美学检查.md)，以及 2026-09-27 至 10-07 的 OPPO PGAM10 真机走查。旧文档保留当时证据；下表按当前状态区分缺陷、体验建议与待验证风险，不把旧版问题直接复制为当前缺陷。

## V2.2.0 修复进度

- C-01：Capacitor `SystemBars` 固定浅色界面使用深色状态栏图标。OPPO PGAM10 夜间模式截图已复核，时间与系统图标清楚可读。
- C-03：采购复核页集中列出上次拟购、当前排单共需与当前还需购买；按用户意见隐藏冰箱可用量，保留原有拦截规则。已通过前端构建和现有 Node 测试，未重新制造过期采购草稿在真机复测。
- C-04、C-05：无菜单日去掉全横线营养卡与重复空状态；部分估算提示加重；日期条明确提示可横滑。真机已复核无菜单日和日期提示。
- C-06：冰箱分类与期限合入搜索框右侧一个筛选弹窗，取消独立分类栏。真机确认两项可同时选中，筛选计数和空结果提示正常。
- C-07：菜谱无图占位改显示菜名开头两字，真机 8 道菜列表无截断；空餐次改两列，真机首屏可见当日预计营养。
- C-08、C-09：设置入口收紧，AI Key、坚果云密码和本地同步时间状态清楚；备份页弱化恢复操作。真机已复核设置各入口与空备份状态。
- C-10、C-11：菜谱编辑键盘展开时收起保存栏，键盘关闭后恢复；菜篮子名称、需买量、分类同排并隐藏冗余库存量。真机已复核上述布局与键盘恢复。
- 新增：点单搜索框与菜谱页白底、米黄边框和高度统一，真机双页对照通过。
- 新增：菜单“当日／周”切换缩小且配色统一，真机切换通过；新建菜谱图片入口、分类标签、黄色导入入口与导入页双按钮已按后续反馈调整。步骤计时按步骤可选添加，详情与菜单快照共用计时器；最终真机闭环仍需完成。
- 后续反馈：步骤表格的空计时原显示为横线，需从三点菜单再选“添加时间”才能输入；菜单可多行同时展开，点外部不收起。已改为空状态直接显示“＋计时”，点一次即聚焦分钟输入，留空失焦恢复按钮；菜单互斥，选中操作或点外部收起。2026-10-08 原签名覆盖安装后，人工点按确认空状态、数字键盘和点外部收起；截图见 `.android-tools/device-logs/20261008-011405/step-fix-*.png`。未保存临时测试步骤，详情计时器启动／暂停仍待真机闭环。

源码已升 `2.2.0 / code 22`，公开包与本地开发者包均用原证书签名并在测试机上保留数据覆盖安装。2026-10-08 将安装前与公开版测试后业务状态逐字段对照，菜谱 8 道、待分配点单 14 条、采购草稿 2 条、冰箱 2 批、周菜单 3 周及其他设置均相同；临时测试步骤已撤销，草稿也恢复一致。公开版的 17 个前端资源逐字节对应隔离构建，APK 凭据扫描无命中，`debuggable=false`。发布包仅含公开 APK 和校验文件，本地开发者版留在忽略目录 `.android-tools/release-v2.2.0/`。下方表格仍是 V2.1.11 检查时的原始问题记录，以上述进度为当前状态。

## 历史问题的当前去向

以下旧评估项已有实现或后续真机记录，不能作为 V2.1.11 新缺陷重复列出：点单加号与确认文案、周菜单阅读顺序和历史做法快照、日期年月定位、餐次重复选择、分组设置、采购勾选与入库、手动采购、菜谱草稿切换保护与保存反馈、失效图片隔离、库存保存方式与期限重算的耦合。对应变更及验证边界详见上述三份历史文档与《开发进度》。

历史评估仍留下专项验证或产品选择：长冰箱列表中找菜入口的可发现性、菜谱封面与导入素材真机观感、桌面周表单日营养摘要、较大数据量下保存与图片性能、TalkBack、后台提醒准时投递，以及真实 AI、坚果云冲突和分享面板。g/kg 换算、快捷消耗、直接到期日等能力候选需要先明确业务规则；不列为现有实现错误。

## 已排除的误判与覆盖边界

- “点单加号进入详情”是使用缩放截图坐标造成的误点；空冰箱的推荐和清空入口实际禁用；周回顾的周日可以横滑访问；启动时自动同步已写入较新的产品需求。
- 本轮以人工点按真机、只读代码和少量截图审阅为主，未用自动化脚本代替界面检查。系统照片选择器已打开并检查静态布局，未选择私人图片。菜谱名称输入框与键盘可见，后续字段可滚动。
- 未发起真实 AI 请求、云同步或备份恢复；不能据此断言这些外部服务通过。2026-10-07 已以原签名同版本 APK 覆盖安装测试机；安装前后数据库业务状态哈希一致，均为 8 道菜谱、14 条待分配点单、2 条采购草稿、3 周菜单和 6 张图片。随后人工复核并将“葱姜蒜沫”1g 入库，此后的库存增加与已买草稿清除属于预期业务变化。备份位于忽略目录 `.android-tools/device-logs/20261007-152818/preinstall-data.tar`。2026-09-27 与 10-07 的早期诊断日志文件为空，不能把“无日志”解释为“无异常”。
